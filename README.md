# Club Deportivo Villa El Lago

Sitio web estático (HTML + Tailwind CSS por CDN + Alpine.js por CDN). Sin instalación ni compilación.

## Páginas
index.html, equipo.html, calendario.html, galeria.html, club.html, contacto.html

## Cómo verlo
Abre `index.html` en el navegador (necesita internet para cargar Tailwind, Alpine y las fuentes).

## Cómo publicarlo (GitHub Pages)
1. Sube todos los archivos a un repositorio de GitHub (los .html en la raíz y la carpeta `assets`).
2. Settings > Pages > Branch: main, carpeta / (root) > Save.
3. Copia el enlace que aparece y entrégalo junto al enlace del repositorio.

## Imágenes necesarias en assets/img
tabla.jpeg, iconoface.png, iconoinsta.png, innologo.jpg
